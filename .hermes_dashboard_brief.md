## Context (read first)
The companion paper (docs/paper/CHOLERA_PAPER_V10_GEE.docx) rests on two strictly separated evidence tiers:
- **National tier = state-level verified NCDC data**: `backend/data/cholera_real/final_state_cholera_dataset_v2.csv` (1,233 rows, 2021–2025, cumulative per state per epi-week, columns: State,Year,Epi_Week,Month,Suspected_Cases,Deaths,CFR,...,Layout,Confidence,Extraction_Method,Source_URL,monotonic_ok). Model `StateCholeraRecord` (app/models/state_cholera.py), migration `20260901_..._add_state_cholera_records.py`, seeder `app/seed_state_cholera.py`, router `app/routers/state_cholera.py` (prefix /api/states: /summary, /year/{year}, /timeline/{state}, /pilot-lgas). This code exists but has NEVER been deployed; the router IS included in main.py.
- **Sentinel tier**: Cross River 4-LGA 2021 pilot (74 cases). Not this task.
- The old 50,688-row LGA-month panel in `case_reports` was **rejected by the paper** as irreconcilable with NCDC totals. The owner has decided to DELETE those rows in production. After deletion `case_reports` is EMPTY. Code paths that read it (risk_calculator, alert_engine, analytics, lgas, report_service, correlation_service, DashboardKpiRow "Confirmed cases") must degrade gracefully to 0/empty — audit them and fix any that would 500 or show NaN/undefined on an empty table. Do NOT delete the table/model.
- Paper headline national numbers: 2021 epidemic 111,062 suspected cases / 3,604 deaths (NCDC year-end). The verified dataset's per-state year-end snapshots do NOT sum to exactly that (reporting-window differences) — the UI must show the official total from the primary source AND the dataset-derived sum, clearly labelled, never conflate them. Put the official year-end totals in a small constants file with the citation ("NCDC Cholera Situation Report, epi-week 52, 2021").
